COMPILED TOKENS — what the engine actually sees

Syntax: {{ name }} variable · {% for u in users %}…{% endfor %} loop · {% if user.admin %}…{% endif %} conditional. How it works: the template is lexed into tokens (text / variable / tag), then walked with the data context — variables are looked up (dot paths supported), tags control the walker. ~80 lines below, open devtools → sources. Real engines add escaping, filters, and inheritance on top of exactly this.
