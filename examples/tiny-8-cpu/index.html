TINY-8 CPU

A complete working 8-bit CPU in one file: fetch → decode → execute cycle, 4 registers, 32 bytes of RAM, and a tiny assembly language you can program right here. Every OS boots on top of exactly this loop.

What's happening: every cycle the CPU does fetch (read instruction at PC) → decode (match opcode) → execute (mutate registers/RAM). That's the loop inside every processor on earth — yours just runs at 12 Hz instead of 5 GHz so you can watch it. The assembler (labels → addresses), the flags register, and memory-mapped OUT are the same ideas an OS kernel builds on. Full implementation ~200 lines below — open devtools → sources.
