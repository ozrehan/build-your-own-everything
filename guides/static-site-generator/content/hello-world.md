# Hello, Static World

Welcome to my tiny blog. This site was generated by **ssg.py**, a static
site generator written in *one* Python file with no dependencies.

## Why static?

Static sites are **fast**, *cheap to host*, and easy to cache. Every page
is plain HTML, so any web server can serve them -- even the
[tiny web server](../) from this series.

Here is some `inline code` to admire.

## A list of things I like

- Python's standard library
- Plain text files
- Generators that finish in milliseconds

## Steps to publish

1. Write a Markdown file
2. Run `python3 ssg.py`
3. Upload the `site/` folder anywhere
